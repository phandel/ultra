Point this page at a feed with ?tb=<public-device-id> for ThingsBoard Cloud, or ?src=<json-url> for any plain JSON endpoint. Defaults live at the top of the script in live.html.

The feed is the JSON that racecollect.sh writes on the phone and racepush.sh publishes. The ThingsBoard access token is a write credential and belongs only in push.conf on the phone — this page reads with anonymous public auth and needs no secret.

Note this page is served over HTTPS, so it cannot read a plain-HTTP address on the local network — for the on-the-same-Wi-Fi case, open the phone's own dashboard on port 8081 directly instead.
